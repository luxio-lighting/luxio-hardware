# LX0002 circuit

U1 is ESP32-S3FH4R2 (C3013940), with 4MB in-package Quad-SPI flash and 2MB Quad-SPI PSRAM. Its QFN56 body remains 7×7mm with 0.4mm pitch, but the exposed pad is 5.7×5.7mm rather than 4×4mm. It therefore uses the dedicated FH4R2 footprint and a redesigned fanout. The 40MHz clock, ceramic antenna matching network, power bypassing and button circuit retain the LX0001 values and functional pin connections. External flash U10, its bypass C110, clock resistor R105 and chip-select pull-up R110 are removed. Package pads 28 and 30–35 are reserved for the in-package memories and left unconnected on the PCB; they are not available user GPIO. C108 100nF and C109 1µF remain close to VDD_SPI pin 29. FH4R2 factory eFuses select 3.3V for this supply; GPIO45 therefore needs no external pull-down: R102 is removed and package pad51 is NC. GPIO46, BOOT and EN retain their existing external pull resistors. The FH4R2 eFuse defaults are documented in Espressif’s [chip-variant VDD_SPI table](https://www.espressif.com/sites/default/files/documentation/esp32-s3-wroom-2_datasheet_en_0.pdf), Table 5; the current schematic guidance confirms that the GPIO45 resistor is optional for this fixed-voltage case. Optional UART testpads TP11/TP12 are omitted, leaving GPIO43/GPIO44 unconnected; native USB programming remains available. GPIO16 and GPIO17 drive the two always-enabled SN74AHCT1G125 buffers; the two strip data contacts have 100Ω series resistors. The buffer supplies connect to USB5V. Output pull-downs R17/R28 are omitted: with OE tied low, the buffers actively drive low whenever their inputs are held low by R18/R29. The shared strip/buffer supply removes the independently powered output case. There are no off-package memory components. R106 is a fitted 0805 zero-ohm bridge (C17477) from +3V3 to +3V3_ANALOG, feeding only VDDA pins 55/56 and C105. This front-side component crosses the crystal traces without cutting their lower-layer ground reference. C106 remains on the main 3.3V rail. The manufacturer specifies less than 50mΩ and 2A for this jumper; the supply-path review includes a separate 50mΩ component bound.

USB VBUS connects directly to the LED VCC output and to the 3.3V buck input. There is no external supply input, source switch, power-path diode, boost converter, fuse or current limiter. The two CC pins each have their own 5.1kΩ pull-down. U2 retains USB data-line ESD protection. D4 retains the two Schottky diodes that isolate BOOT and GPIO18 at the shared button.

The USB connector is rated 3A at 5V. This is a connector ceiling for the total controller-plus-strip current, not negotiated current or a promise that every USB source can provide it. The adapter and cable must also support the load. AHCT operation is specified from 4.5V to 5.5V; rail droop caused by cable loss or excessive strip current can compromise the data output.

The LMR51410YFDBVR synchronous buck is retained from LX0001. C8 and C19 are parallel 10µF 10V 0603 input capacitors (C19702), replacing the former 10µF 50V 1206. Two are used because DC bias substantially reduces their capacitance at 5V; a single part has insufficient tolerance margin around the TI 2.2µF recommendation. R22/R23/R24 use 0402 packages with unchanged 100kΩ/22kΩ/10kΩ values to reduce occupied area. It accepts 4V–42V, supports 1A output and uses the original 10µH inductor, two 22µF output capacitors and 100kΩ/(22kΩ+10kΩ) feedback divider for nominal 3.3V. Its internal MOSFETs provide synchronous rectification; no external power diode is needed. A linear replacement would dissipate 0.51W at 300mA or 0.85W at 500mA from 5V, so the switching regulator is preferable inside the small PLA enclosure.

The removed components are J2, F1, Q1, Q2, Q3, U3, U4, U5, U7, C5, C7, C12, C13, C18, D1, D2, D3, L2, R10, R12, R13, R14, R15, R17 and R28. The in-package-memory revision additionally removes U10, C110, R105, R110 and R102. The project has 55 populated components, 8 test pads and one DNP antenna-tuning footprint. Test pads TP8 and TP9 now both expose USB5V. R30 retains its 10kΩ pull-up value in a smaller 0402 package (C25744), shared with the other 10kΩ core resistors.

`tools/generate.py` creates the schematic, `parts.json` and `connections.csv`; PCB construction is separate. `tools/verify_circuit.py` validates the exported KiCad XML netlist against the required USB-only topology and checks the retained LX0001 core connections, exact FH4R2 variant, reserved memory pads and VDD_SPI capacitor bank. PCB DRC, routing, impedance, thermal and physical assembly verification remain separate checks. Final RF matching and thermal performance need measurements on the assembled LX0002 board.
