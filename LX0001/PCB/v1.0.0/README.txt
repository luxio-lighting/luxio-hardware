LX0001 v1.0.0 PCB

Current device documentation and PCB renders: ../../README.md#pcb

Source/
  Open Source/LX0001.kicad_pro in KiCad 10. The schematic, routed board,
  project-local libraries, design notes and checking/export tools are here.
  Read Source/tools/README.txt before running authoring or routing scripts.

Assets/
  Manufacturer datasheets, supplier models, sourcing evidence and historical
  review snapshots. Assets/review-history is not a current fabrication input.

Export/
  Current Gerbers, JLCPCB BOM/CPL, schematic PDF, assembly drawings, PCB renders
  and verification records. See Export/README.txt for fabrication instructions.

The enclosure source, reference assets and printable files are separate in
../../Enclosure/v1.0.0/. Directory organization does not change the PCB design.
