LX0001 v1.0.0 — ESP32-S3 / 4MB flash / ceramic antenna core
Checked: 2026-11-11

IMPLEMENTED CORE
30 positions (29 fitted, one DNP tuner) in core_parts.json. Bare ESP32-S3 C2913192 + external Winbond
W25Q32JVSSIQ C179173, 32Mbit = 4MB. No PSRAM. U1 is the bare 7x7mm,
56-pin QFN with 4x4mm exposed ground pad, not ESP32-S3FH4R2.
U10 uses the 5.3x5.3mm SOIC-8 body; a 3.9mm SOIC is NOT a substitute.
All selected footprints were loaded in installed KiCad Python and every
assigned electrical pin was checked against the footprint's pad numbers.

PIN ASSIGNMENT / FIRMWARE CONTRACT
GPIO0 / physical5 = BOOT, external10k pullup. Root schematic owns button.
GPIO1 / physical6 = CC1_SENSE, ADC1_CH0.
GPIO2 / physical7 = CC2_SENSE, ADC1_CH1.
GPIO4 / physical9 = VBUS_SENSE, ADC1_CH3.
GPIO5 / physical10 = USB_STRIP_EN output.
GPIO6 / physical11 = USB_HIGH_CURRENT output.
GPIO16 / physical22 = LED data output1. Native symbol names pin XTAL_32K_N;
this is also GPIO16. No external32kHz crystal is populated.
GPIO17 / physical23 = LED data output2.
GPIO18 / physical24 = GPIO18_BUTTON input.
GPIO19 / physical25 = USB_DM.
GPIO20 / physical26 = USB_DP.
GPIO21 / physical27 = DATA_ENABLE output.
U0TXD / physical49 = UART_TX (GPIO43).
U0RXD / physical50 = UART_RX (GPIO44).
GPIO45 / physical51 has10k pulldown: select3.3V flash supply at reset.
GPIO46 / physical52 has10k pulldown: permits ROM download when BOOT low.
GPIO3 strapping pin is left at default; no external load.
Firmware must initially keep USB_STRIP_EN, USB_HIGH_CURRENT and DATA_ENABLE
low until the main power-path conditions are validated. These three nets
are normal non-strapping GPIOs. Root IO circuitry must give safe external
pulldowns during boot/reset. Configure4MB flash, PSRAM disabled; validate
flash boot at conservative40MHz DIO before qualifying higher modes/speeds.

POWER AND RESET
Provide3.3V with at least500mA available at the MCU, including WiFi bursts.
Do not let VDD3P3_RTC fall below3.0V. L100=2nH900mA isolates VDD3P3 RF
supply pins2/3, with local bypass capacitors. RTC pin20, CPU pin46 and VDDA
pins55/56 receive3V3 with local bypass. Pin57 exposed pad requires ground
copper and multiple short ground vias; use paste-windowed stencil.
VDD_SPI pin29 is an internal3.3V source through approximately14ohm from
VDD3P3_RTC. It powers the external flash and has0.1uF+1uF local bypass.
Do not connect VDD_SPI directly to the3V3 net or add excessive capacitance.
KiCad stock ESP32-S3 symbol calls VDD_SPI power_input; a power flag on
VDD_SPI records the intended internal power source for ERC.
ESP_EN uses10k/1uF RC, held low for reset. Native USB and UART test points
provide programming/recovery access. The root circuit owns USB termination,
ESD, connector, reset test point and BOOT/button wiring.

40MHZ CLOCK
HD7B040000M01 C655034:40MHz,12pF load,initial tolerance±10ppm, stability
±20ppm over−20..+70C, ESR<=25ohm,100uW maximum drive,3.2x2.5mm4-pad.
Pins1/3 active and2/4 ground. Manufacturer1.4x1.2mm land pattern agrees
with KiCad Crystal_SMD_3225-4Pin_3.2x2.5mm.
C112/C11318pF C0G are starting values from CL=C1*C2/(C1+C2)+Cstray,
assuming about3pF total stray. Measure and adjust frequency on assembled
hardware. L10124nH in series with XTAL_P is explicitly recommended as an
initial value by Espressif to reduce RF harmonic coupling. Do not omit it
without the corresponding RF/clock measurements. Keep crystal and load
capacitors close; solid ground below, ground shielding around the clock,
no buck switching nets or other fast signals in this area.

RF MATCH / ANTENNA (updated for centered input connectors)
U1 LNA_IN pin1 -> C114 shunt 1.5pF -> L102 series 2.7nH -> C115 shunt
1.5pF -> RF_50 feed -> ANT1. These chip-match values remain starting
values, not measurements on this board. All ground connections are short
and have adjacent ground vias.

ANT1 is now Walsin RFECA3216060A1T C127620, nominal 3.1x1.6x0.6mm,
manufacturer V09 Type1 middle-edge pattern. The previous RFANT corner
antenna is superseded because the input connectors are centered.
Manufacturer specifies an 8x3mm empty region, PCB length L>30mm and
antenna offset D>6mm. Our 60x20mm board satisfies these size limits;
the 90x40mm/0.8mm test board is not equivalent to our actual stackup.

Custom footprint Core:Walsin_RFECA3216060A1T_Type1 reproduces V09 p3:
- FEED and GND lands at the marked end are each 0.35x0.65mm, with a
  0.30mm gap. Opposite TUNE land is 0.35x1.60mm. End-land centers are
  2.95mm apart, spanning the 3.30mm maximum package length.
- Separate F.Cu-only pads reproduce the 2.7mm feed/ground fingers and
  1.8mm tuning finger. Only manufacturer solder lands have mask/paste.
- Three symbol ports map the three PCB lands: 1=RF_50, 2=ANT_TUNE,
  3=GND. They are not three independently numbered package terminals.
- L104 is an optional DNP 0402 tuning position from ANT_TUNE to GND;
  the manufacturer specifies no value. Its BOM candidate is 0 ohms,
  but DO NOT populate that link without RF measurement. The former
  6.8nH RFANT series matching element has been removed.

Placement: ANT1=(14.5,1.5), rotation 0; L104=(11.1,1.5), rotation 0.
Both-layer empty window x10.5..18.5,y0..3mm allows only intentional top
antenna pattern copper. Bottom copper/vias/components are prohibited.
FEED solder pad=(15.975,1.975), GND=(15.975,1.025), TUNE=(13.025,1.5).
The full feed finger ends at (18.5,1.975); ground finger at (18.5,1.025).
The short 0.50mm feed transition bends down-left inside the empty region
before joining the nominal 0.80mm grounded coplanar section. This deviates
from the manufacturer's test-board exit shape and must be tuned on the
actual assembly. Neither segment is asserted to be measured 50 ohms.

Source/tools/rf_fanout.py owns all RF traces and four RF ground vias.
C115 is rotated 270 degrees; C114 and L102 keep their existing locations.
Clock C112 ground via is moved to (19.05,2.4) by clock_fanout.py.
Preserve continuous backside ground under the feed after it exits the
antenna window, with no signal cuts or supply islands. Bottom R25/R26
must leave that corridor and R31 must leave the antenna window.
The routing reference corridor is recorded in antenna_routing_proposal.json.
A temporary router-only keepout must leave holes around existing ground
vias; do not convert that corridor into a KiCad copper-pour keepout.
The 0.80mm/0.15mm coplanar dimensions still require a stackup calculation
and final antenna/matching measurement. Qualify with final enclosure,
connector cables and screw hardware present.

RELEASE VALIDATION
The firmware, clock-load values, RF matching, conducted spurious emissions,
radiated performance, temperature operation and antenna efficiency have
not been measured on hardware. Manufacturer reference results do not prove
performance of this60x20mm board. First-article VNA/OTA/RF compliance and
clock-offset tuning are required before claiming a production-qualified
radio. Antenna datasheet explicitly says resonance must be adjusted with
the matching circuit. No module radio certification transfers to this bare
chip implementation. Complete the parent design's power/thermal5A checks
as well.

INDEPENDENT INTEGRATION AUDIT
The generated hierarchical schematic was exported with KiCad CLI to XML.
200 assigned core,USB,data-output andbuttonpins matched parts.json exactly.
Manufacturer pin maps for USBLC6-2SC6 and AHCT1G125 were checked;
3V3-to5V translation,default-disabled OE logic,andBAT54C button-isolation
polarity are correct. This verifies connectivity, not firmware or PCB routing.
The initial automatic placement had RF bypass and clock-series components
too far from MCU pins. Core placement recommendations are recorded in
core_placement_recommendations.json; parent owns their final integration.
The RF bypass must be local to pins2/3, RTC bypass local to20, CPU bypass
local to46,andVDDA bypass local to55/56. Route each directly before the
rest of3V3 distribution. Ground-via proximity matters as much as distance.
Keep flash SPI under30mm and prefer40MHzDIO for initial bringup. Keep USB
as a paired90ohm differential route with ESD nearconnector and22ohm
series resistors nearMCU. Firmware must establish available USB current
and strip voltage mode before enabling strip/data. Hardware cannot detect
whether an attached strip is5V,12V or24V.

Layout update: five optional 0-ohm data/CS tuning links removed for density.
R105 clock series footprint and R110 CS pull-up retained. Direct point-to-point
flash data wiring; begin bring-up at40MHz DIO and qualify before80MHz/QIO.
This preserves electrical function but reduces later per-line tuning options.
